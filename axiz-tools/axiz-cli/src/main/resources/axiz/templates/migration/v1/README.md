# Version 1.0.0 workflow baselines

These resources were extracted from the locally retained artifact
pe.axiz:axiz-codegen-templates:1.0.0. They are used only to
recognize unchanged generated workflows through semantic YAML comparison before migration.
They are never emitted as active workflows of a 2.x project. Existing workflow customizations
produce a review proposal instead of being silently replaced. Rendering uses the shared
TemplateSet engine; the new workflows come from the current framework templates.

The .fixture suffix identifies inert comparison data, never runnable workflow files.
