# quality

Machine-checked rules: `axiz-code-standards` (Checkstyle, SpotBugs, Spotless, Semgrep, Spectral and
gitleaks configurations referenced by the parents), `axiz-archunit-rules` (rules services run in
their tests), `axiz-architecture-tests` (layer rules of the framework itself) and
`axiz-coverage-report` (aggregated coverage, not published).
