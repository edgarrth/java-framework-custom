===== axiz  --help
Usage: axiz [-hV] [COMMAND]
axiz platform: create services from a contract and keep them coherent with the
structure.
  -h, --help      Show this help message and exit.
  -V, --version   Print version information and exit.
Commands:
  new          Creates a project from an archetype (interactive with -i).
  add          Adds capabilities to the service (see axiz catalog capabilities).
  generate, g  Generates usecase, command, query, handler, event,
                 event-handler, entity, repository, controller, dto, mapper,
                 http-client, migration, error-code or test.
  contract     Works with the OpenAPI and AsyncAPI contracts of the service.
  upgrade      Upgrades the axiz version applying the OpenRewrite recipes.
  doctor       Checks tools, versions, contract, configuration and
                 anti-patterns.
  local        Starts or stops the local dependencies (compose.yaml).
  catalog      Lists archetypes and capabilities.
===== axiz new --help
Usage: axiz new [-hiV] [--force] [-a=<archetype>] [--asyncapi=<asyncapi>]
                [--axiz-version=<axizVersion>] [-d=<dir>]
                [--description=<description>] [-f=<structure>] [-g=<group>]
                [-o=<output>] [--openapi=<openapi>] [-p=<persistence>]
                [--package=<basePackage>] [-s=<stack>] [--server=<server>]
                [-c=<capabilities>]... [--extension=<extensions>[,
                <extensions>...]]... [<name>]
Creates a project from an archetype (interactive with -i).
      [<name>]              Project capability name in kebab-case, e.g.
                              payment-orders.
  -a, --archetype=<archetype>
                            Archetype (see axiz catalog).
      --asyncapi=<asyncapi> AsyncAPI contract of the events (optional).
      --axiz-version=<axizVersion>
                            Structure version (default: the one of this CLI).
  -c, --capability=<capabilities>
                            Extra capability (repeatable).
  -d, --dir=<dir>           Project directory (default: current directory).
      --description=<description>
                            One-line description.
      --extension, --extensions=<extensions>[,<extensions>...]
                            Optional extensions: cqrs (hexagonal only).
  -f, --structure=<structure>
                            Structure: layered, hexagonal, eda, bff, batch.
      --force               Overwrite files of an existing folder.
  -g, --group=<group>       Maven group (default pe.axiz.<domain>).
  -h, --help                Show this help message and exit.
  -i, --interactive         Asks for every missing value.
  -o, --output=<output>     Directory where the project folder is created.
      --openapi=<openapi>   OpenAPI 3.1 contract (required by archetypes
                              exposing REST).
  -p, --persistence=<persistence>
                            none, aurora or dynamodb (aurora is JPA on servlet,
                              R2DBC on reactive).
      --package=<basePackage>
                            Base package (default pe.axiz.<domain>.<service>).
  -s, --stack=<stack>       servlet or reactive.
      --server=<server>     initializr URL (online mode); token from AXIZ_TOKEN.
  -V, --version             Print version information and exit.

Examples:
  axiz new payment-orders --archetype business --structure hexagonal --openapi
api.yaml
  axiz new notifications-processor --archetype event-processor -c inbox -c
messaging-sns
  axiz new -i

===== axiz generate --help
Usage: axiz generate [-hV] [--force] [--category=<category>]
                     [--contract=<contract>] [-d=<dir>] [--source=<source>]
                     [--target=<target>] [--title=<title>] <type> <name>
Generates usecase, command, query, handler, event, event-handler, entity,
repository, controller, dto, mapper, http-client, migration, error-code or test.
      <type>              Artifact type.
      <name>              Name, e.g. approve-payment.
      --category=<category>
                          error-code: error category (default UNPROCESSABLE).
      --contract=<contract>
                          http-client: OpenAPI contract of the API to call.
  -d, --dir=<dir>         Project directory (default: current directory).
      --force             Overwrite existing files.
  -h, --help              Show this help message and exit.
      --source=<source>   mapper: source type.
      --target=<target>   mapper: target type.
      --title=<title>     error-code: title.
  -V, --version           Print version information and exit.

Examples:
  axiz generate usecase approve-payment
  axiz generate error-code limit-exceeded --category unprocessable --title
"Daily limit exceeded"
  axiz generate http-client core-banking --contract core-banking.yaml
  axiz generate mapper payment --source CreatePaymentRequest --target pe.axiz.
payments.domain.Payment
===== axiz contract --help
Usage: axiz contract [-hV] [COMMAND]
Works with the OpenAPI and AsyncAPI contracts of the service.
  -h, --help      Show this help message and exit.
  -V, --version   Print version information and exit.
Commands:
  sync  Generates new operations, proposes updated controllers and checks
          compatibility.
  lint  Checks the contract against the axiz rules (same as the Spectral
          ruleset).
  diff  Reports changes between two contract versions; exit 1 when breaking.
===== axiz upgrade --help
Usage: axiz upgrade [-hV] [--dry-run] [--skip-rewrite] [-d=<dir>]
                    [--rename=<rename>] [--to=<to>]
Upgrades the axiz version applying the OpenRewrite recipes.
  -d, --dir=<dir>         Project directory (default: current directory).
      --dry-run           Run the migration in an isolated copy and retain its
                            patch without changing sources.
  -h, --help              Show this help message and exit.
      --rename=<rename>   New deployment name; preserves stateful identities
                            and Java packages.
      --skip-rewrite      Only update the versions.
      --to=<to>           Target version (default: the version of this CLI).
  -V, --version           Print version information and exit.
===== axiz doctor --help
Usage: axiz doctor [-hV] [-d=<dir>] [--outbox-jdbc-url=<outboxJdbcUrl>]
                   [--outbox-table=<outboxTable>]
Checks tools, versions, contract, configuration and anti-patterns.
  -d, --dir=<dir>   Project directory (default: current directory).
  -h, --help        Show this help message and exit.
      --outbox-jdbc-url=<outboxJdbcUrl>
                    Read-only outbox diagnostic report (PostgreSQL);
                      credentials from AXIZ_DOCTOR_DB_USER/PASSWORD.
      --outbox-table=<outboxTable>
                    Outbox table for the optional diagnostic report.
  -V, --version     Print version information and exit.
