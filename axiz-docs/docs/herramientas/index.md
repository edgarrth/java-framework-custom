# Herramientas

La CLI, el initializr web y el pipeline del framework usan el **mismo motor de generación**
(`pe.axiz:axiz-codegen`) y las mismas plantillas, versionadas con el framework: un proyecto creado

- [CLI](cli.md): crear, hacer crecer, diagnosticar y actualizar servicios.
- [Referencia de la CLI](cli-referencia.md): la ayuda de cada comando.
- [Initializr](initializr.md): la web y su API.
- [Contrato primero](contratos.md): cómo se generan modelos, controladores y clientes desde los
  contratos, y cómo se evoluciona un contrato sin romper a sus consumidores.
