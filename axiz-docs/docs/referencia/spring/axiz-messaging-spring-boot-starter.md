# axiz-messaging-spring-boot-starter

Publicadores y consumidores CloudEvents para MSK, SQS y SNS con reintentos, DLQ e integración con inbox.

## Dependencia

```xml
<dependency>
  <groupId>pe.axiz</groupId>
  <artifactId>axiz-messaging-spring-boot-starter</artifactId>
</dependency>
```

La versión la gestiona `axiz-bom` (los servicios heredan `axiz-parent-service`).
