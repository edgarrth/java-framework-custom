# axiz-soap-spring-boot-starter

Clientes SOAP con parseo XML seguro: timeouts, WS-Security, mapeo de faults, logs enmascarados y observaciones.

## Dependencia

```xml
<dependency>
  <groupId>pe.axiz</groupId>
  <artifactId>axiz-soap-spring-boot-starter</artifactId>
</dependency>
```

La versión la gestiona `axiz-bom` (los servicios heredan `axiz-parent-service`).
