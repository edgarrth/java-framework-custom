# axiz-tenancy-spring-boot-starter

Resolución del tenant desde el token o una cabecera confiable y propagación a HTTP, mensajería e Hibernate.

## Dependencia

```xml
<dependency>
  <groupId>pe.axiz</groupId>
  <artifactId>axiz-tenancy-spring-boot-starter</artifactId>
</dependency>
```

La versión la gestiona `axiz-bom` (los servicios heredan `axiz-parent-service`).
