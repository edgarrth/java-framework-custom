# axiz-tokenization-vault-spring-boot-starter

Starter de dependencias para el servidor genérico de bóveda. Incluye únicamente su
autoconfiguración base; la integración del almacén, el presupuesto distribuido, criptografía,
auditoría confirmada y perfiles especializados se seleccionan explícitamente.

Consultar configuración, colaboradores obligatorios y pruebas en
[axiz-tokenization-vault-spring-boot-autoconfigure](axiz-tokenization-vault-spring-boot-autoconfigure.md).

Este artefacto no es el cliente remoto de tokenización y no incorpora SDK AWS/Redis ni PAN
como dependencia obligatoria.
