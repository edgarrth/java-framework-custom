# axiz-cache-spring-boot-starter

@AxizCacheable con Caffeine como L1 y Redis (ElastiCache) como L2, TTL por caché y tolerancia a fallos.

## Dependencia

```xml
<dependency>
  <groupId>pe.axiz</groupId>
  <artifactId>axiz-cache-spring-boot-starter</artifactId>
</dependency>
```

La versión la gestiona `axiz-bom` (los servicios heredan `axiz-parent-service`).
