# axiz-resilience-spring-boot-starter

Valores por defecto de Resilience4j (circuit breaker, bulkhead) y @Retryable de Spring configurados por propiedades.

## Dependencia

```xml
<dependency>
  <groupId>pe.axiz</groupId>
  <artifactId>axiz-resilience-spring-boot-starter</artifactId>
</dependency>
```

La versión la gestiona `axiz-bom` (los servicios heredan `axiz-parent-service`).
