# axiz-dependencies

Versiones de todas las librerías de terceros que usa la plataforma (trenes de Spring Boot y Spring
Cloud, AWS SDK v2, Testcontainers, herramientas de análisis, etc.). Es el único lugar donde se decide
la versión de un tercero; Renovate propone las actualizaciones y las versiones mayores requieren
comprobaciones de dependencias y de compatibilidad. Lo importan los parents y quienes usan `axiz-bom`.
