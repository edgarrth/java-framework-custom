# extensions

Patrones estructurales opcionales. CQRS extiende hexagonal con buses y comportamientos separados para comandos y consultas, y compone las capacidades del núcleo mediante cableado Spring.

Se compila desde la raíz del framework con `./mvnw verify`. Las reglas de dependencias están en la guía de arquitectura del framework.
