# kits

APIs públicas de tecnología que usan los adaptadores de persistencia de los servicios. Los kits tienen scope compile y se limitan a los paquetes de persistencia. No dependen de Spring ni de capas superiores.

Se compila desde la raíz del framework con `./mvnw verify`. Las reglas de dependencias están en la guía de arquitectura del framework.
